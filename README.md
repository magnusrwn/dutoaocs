# Welcome to Dutoaocs.

---

AI is good enoguh to create good architecture. It just needs a bit of controling. **dutoaocs** *will be* a completetly free CLI tool designed to auto-create, update, and manage documentation for any project.

You keep the power of choosing context and architecture of the documentation. It just reads context and writes docs.

It will link to your existing AI subscription (Claude, OpenAI, ...), so there is no need to charge for anything here.
